## Update (2026-10-15)

CI now pins Go 1.26.9 exactly (`go-version: "1.26.9"`), because `"1.26"` let setup-go reuse an
older cached 1.26.x with standard-library advisories fixed in 1.26.9. The image build stage moves
to `golang:1.26.9-alpine` (digest in the table above), so the shipped binary is built with the
patched standard library. Rerun locally with Go 1.26.9: `go vet ./...` clean,
`go test -count=1 ./...` passes, govulncheck v1.8.0 finds no vulnerabilities. Dependabot update
pull requests are paused (`open-pull-requests-limit: 0`) so the repository keeps a single `main`
branch.
